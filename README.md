# TeamReady

Interactive preview for a player wellness and team-readiness platform.

## Included flows

- Organisation owner signup
- Multiple staff and coach roles
- Team creation
- Player email invitation management
- Player onboarding and consent
- Twelve-question daily wellness check-in
- Coach dashboard with team readiness heatmap
- Team pain map and priority alerts
- Individual player readiness and trend view

## Run locally

```bash
npm install
npm run dev
```

Open the local URL displayed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Current scope

This branch is a front-end product preview using sample data. Authentication, email delivery, persistence, permissions, and health-data security require backend implementation before production use.
